# Sarcastic Gym Trainer AI

An interactive AI chatbot powered by Ollama that acts as a sarcastic gym trainer. It responds to workout excuses, skipped days, and diet cheats with witty sarcasm, short motivational pushes, and mini workout challenges.

## Tech Stack
* **Python**
* **Ollama** (Local LLM framework)

## Features
* Uses custom system prompting to deliver a sarcastic, humorous trainer persona.
* Teases workout excuses while encouraging accountability.
* Concludes responses with actionable mini fitness challenges (e.g., "20 squats. Now.").

## How to Run

1. Clone this repository:
```bash
git clone https://github.com/Yashfeen123/sarcastic-gym-trainer-AI.git
```
2. Install dependencies:
```bash
pip install ollama
```
3.  Ensure Ollama is running locally,then execute the script:
```bash
python ola.py
```
